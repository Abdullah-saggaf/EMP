# EMP – Multilingual Real-Estate Website

A property listings website built with Next.js, available in six languages including right-to-left Arabic.

## Features

- Property catalogue with search by city, country, type or name
- Filters by country and property type, and sorting by date or price
- Full internationalisation in English, Arabic, German, Spanish, Polish and Turkish using `next-intl`, with locale-aware routing
- Pages for services, courses, about and contact
- Animated, responsive UI

## Tech stack

- Next.js (App Router) and React
- TypeScript
- next-intl for translations and locale routing
- Tailwind CSS and Framer Motion
- React Hook Form with Zod validation

## Getting started

```bash
git clone https://github.com/Abdullah-saggaf/EMP.git
cd EMP
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
